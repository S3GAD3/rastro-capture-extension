# Seguridad

RASTRO CAPTURE no debe utilizarse para eludir autenticación, cifrado, DRM ni controles de acceso. La extensión actúa únicamente sobre la pestaña que el usuario activa de forma expresa.

Para comunicar una vulnerabilidad, evita incluir datos reales de investigaciones, credenciales, cookies o contenido personal. Describe el problema con una página de prueba o un caso reproducible sin información sensible.

Los archivos exportados pueden contener datos personales y material sensible. Deben almacenarse y compartirse conforme a los procedimientos de la unidad investigadora.
